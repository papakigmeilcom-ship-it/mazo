MAZO — GitHub Pages

1. Βάλε το αρχείο του βίντεό σου στον ίδιο φάκελο με τα αρχεία του site.
2. Μετονόμασέ το σε video.mp4 (ή άλλαξε το όνομα στο index.html).
3. Ανέβασε ΟΛΑ τα αρχεία του φακέλου στο νέο GitHub repository.
4. Στο repository πήγαινε Settings → Pages.
5. Στο Build and deployment διάλεξε Deploy from a branch.
6. Επίλεξε branch main και folder /(root), μετά Save.

Σημείωση: Το GitHub έχει όριο 25 MB για upload από browser και όριο 100 MB ανά αρχείο στο κανονικό Git. Για μεγαλύτερο βίντεο, φιλοξένησέ το σε υπηρεσία video hosting και βάλε το URL του στο source του video στο index.html.
